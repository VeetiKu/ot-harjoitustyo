# Usage Instructions

## Register

- Choose option 2 Register from the home menu
- Create an username and password (minimum lenght 3)
- You should see `"Account Created!"` 

## Login

- Choose option 1 - Login  
- Enter your username and password  
- If successful, you will see `"Welcome, <username>!"`
- You will be taken to the dashboard

## Dashboard

After logging in, you can choose:

- **1 - Overview**
- **2 - Set Budget**
- **3 - Add Expense**
- **4 - Delete Expense**
- **5 - Edit Expense**
- **0 - Logout**

## Overview

- Shows all your expenses in a list  
- Displays:
  - Total amount spent  
  - Remaining budget 

## Set Budget

- Choose option **2 - Set Budget**  
- Enter a number to set your budget  
- The budget will be updated immediately  


## Add Expense

- Choose option **3 - Add Expense**  
- Enter:
  - Expense name  
  - Price  
  - Category  
  - Whether it is recurring (y/n)  
- After adding, you will see:  
  `"Expense added!"`

## Delete Expense

- Choose option **4 - Delete Expense**  
- Select the index of the expense you want to delete  
- If successful, you will see:  
  `"Expense deleted!"` 


## Edit Expense

- Choose option **5 - Edit Expense**  
- Select the index of the expense you want to edit  
- Enter new values for:
  - Name  
  - Price  
  - Category  
  - Recurring status  
- If successful, you will see:  
  `"Expense updated!"` 

## Recurring Expenses

- Recurring expenses are automatically tracked  
- Every ~30 days, they are added again automatically  

## Logout / Exit

- Choose **0** in the dashboard to log out  
- Choose **0** in the main menu to exit
